# Evidence

`ledger.md` is the only source of truth for the Records pages (`#records` in the platform).

It was copied **by hand** from Kaggle `report.md` files, run logs and a threshold-check notebook (October 2026). The original reports, logs and notebooks live **outside this repository**; nothing here was fetched or generated by a script, and the platform never reads them.

Rules for editing the ledger:

- Section ids (`S1` … `S9`) and the line numbers that records cite are checked by `npm run check:records`. If you add or remove a line, re-point the records that cite lines after it, or the check fails.
- Only add numbers that you copied from an original report. If a number is not in a report, it does not belong here.
- Do not "fix" a figure to make two sections agree. Put the disagreement in the PR or in section S8 instead.

The other `kaggle-*.md` and `fine-tune-run2.md` files in this folder are earlier raw excerpts and are **not** read by Records. `fine-tune-run2.md` still says run 2 had no result yet; the ledger (S5) lists run 2 results. Treat the ledger as newer and reconcile the old note by hand.
